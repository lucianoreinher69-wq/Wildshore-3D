# Wildshore 3D — v0.5

Protótipo 3D de sobrevivência para navegador e Android.

## Recursos atuais
- Ilha tropical 3D com árvores, pedras e arbustos.
- Exploração em terceira pessoa e controles para teclado/tela de toque.
- Necessidades de vida, fome, sede e energia.
- Coleta de madeira, pedra e frutas.
- Construção de abrigo e jangada com coleta de fibras.
- Salvamento automático local a cada 5 segundos.
- Opções de qualidade gráfica baixa, média e alta.
- Workflow do GitHub Actions para gerar APK Android de depuração.

## Executar localmente
Abra `www/index.html` em um navegador com internet (Three.js é carregado por CDN).

## Gerar APK
No GitHub: **Actions → Build Wildshore 3D Android APK → Run workflow**.
Ao terminar, baixe o artefato **Wildshore3D-Android-APK**.

O APK gerado pelo workflow é de depuração, não assinado para publicação na Play Store.
